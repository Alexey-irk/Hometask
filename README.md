## Модуль generators 
Модуль `src/generators.py` содержит три функции-генератора для работы с
транзакциями и номерами карт. Все функции используют `yield`, что позволяет эффективно обрабатывать большие объёмы данных
без загрузки всего результата в память.

### `filter_by_currency`

Фильтрует транзакции по коду валюты операции.

### `transaction_descriptions`

Генератор, который поочерёдно возвращает описания транзакций.

### `card_number_generator`

Генератор номеров банковских карт в формате `XXXX XXXX XXXX XXXX`.

## Модуль decorators
Декоратор `log` для автоматического логирования выполнения функций Python. Позволяет гибко выбирать, 
куда направлять логи — в консоль или в файл — и фиксирует как успешные результаты, так и возникшие ошибки.

### Установка

Cкопируйте модуль с декоратором:

```python

    ...
```


##  Модуль src / finance / reader
### Считывание финансовых операций

### Реализованные функции:
*   `read_transactions_csv(file_path: str) -> list[dict]` — считывает операции из файлов формата CSV с помощью библиотеки `pandas`.
*   `read_transactions_xlsx(file_path: str) -> list[dict]` — считывает операции из электронных таблиц Excel (`.xlsx`), используя связку `pandas` и `openpyxl`.

### 🛡 Безопасность и отказоустойчивость
Обе функции обернуты в блоки `try-except`. Если файл отсутствует, заблокирован или поврежден, то:
1. Выведется информативное сообщение об ошибке в консоль.
2. Функция безопасно вернет пустой список `[]`.
